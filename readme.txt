The Cecabank plugin for WooCommerce lets you charge your customers through the Cecabank virtual POS (TPV).

== Description ==

The Cecabank plugin for WooCommerce lets you charge your customers through the Cecabank virtual POS (TPV). At checkout the customer is redirected to the Cecabank payment page to enter their card details, and the order is updated automatically once Cecabank confirms the payment.

It supports full and partial refunds from the WooCommerce order screen, subscriptions through WooCommerce Subscriptions and the block-based checkout.

= More information =

For more information on how to install and configure this plugin, see the plugin manual in the "Help and Resources" section of the Cecabank console.

== Installation ==

You can download the plugin here: https://wordpress.org/plugins/cecabank-woocommerce/developers/.

= Automatic installation =

Automatic installation is the easiest way to install the plugin in WordPress. Log in to your WordPress dashboard, go to the Plugins menu and click "Add New".

In the search field, type "Cecabank WooCommerce Plugin" and click "Search Plugins". Once you have found it, you can view its details, rating and description. Most importantly, you can install it by simply clicking "Install Now".

= Manual installation =

Manual installation means downloading the plugin and uploading it to your server via FTP. The WordPress codex has [an article with instructions on how to do this](http://codex.wordpress.org/Managing_Plugins#Manual_Plugin_Installation).

= Updating =

Updates are applied automatically and work as with any other plugin. In any case, always back up your site before updating, just in case.

= Usage =

To use the plugin you need access to a Cecabank virtual POS (TPV) in order to obtain your credentials.
